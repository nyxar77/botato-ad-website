# botato-ads

Ad booking page for background screen placements, built with Svelte 5, Tailwind CSS, and Bun.

## Development

With Nix:

```bash
nix develop
bun run dev
```

Without Nix:

```bash
bun install
bun run dev
```

## Build

```bash
bun run check
bun run build
```

Output is written to `dist/`.
